# Radball Regie installieren

Lade die passende Datei aus dem [aktuellen Regie-Release](https://github.com/radeddi/radball/releases/latest).

| Gerät | Datei | Installation |
| --- | --- | --- |
| Android ab Version 7, ARM64 | `Radball-Regie-…-Android-arm64.apk` | APK öffnen und Installation aus dieser Quelle erlauben. Eine frühere Test-APK mit anderer Signatur muss zuerst entfernt werden. |
| Linux x86_64 | `Radball-Regie-…-Linux-x86_64.tar.gz` | Archiv entpacken und `Radball-Regie` starten. |
| Windows 10/11 x64 | `Radball-Regie-…-Windows-x64.exe` | Installer starten und anschließend **Radball Regie** aus dem Startmenü öffnen. Python ist enthalten. |

Für die Verbindung zu einer Anzeige müssen beide Geräte im selben lokalen Netzwerk sein. Der Spielbetrieb bleibt lokal möglich, wenn kein Internet verfügbar ist.
